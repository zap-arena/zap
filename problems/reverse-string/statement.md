# Reverse String

Given a string `s`, print the string with its characters in reverse order.

Character case must be preserved, and no characters may be added or removed.

## Input

A single line containing the string `s`.

## Output

A single line containing `s` reversed.

## Example

Input:

```
hello
```

Output:

```
olleh
```

## Constraints

- `1 <= |s| <= 10^5`
- `s` consists of printable ASCII characters excluding newline.
