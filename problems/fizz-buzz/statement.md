# Fizz Buzz

Given an integer `n`, print one line for every integer `i` from `1` to `n` inclusive:

- `FizzBuzz` if `i` is divisible by both 3 and 5
- `Fizz` if `i` is divisible by 3 only
- `Buzz` if `i` is divisible by 5 only
- otherwise the number `i` itself

## Input

A single line containing the integer `n`.

## Output

`n` lines, as described above.

## Example

Input:

```
5
```

Output:

```
1
2
Fizz
4
Buzz
```

## Constraints

- `1 <= n <= 10^5`
