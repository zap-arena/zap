# Contains Duplicate — Code War Chain

This is a **progressive** ("Code War") problem: it unlocks in stages. Each stage
enhances the previous one and reuses the same code editor/boilerplate — only
the statement and the test cases change.

1. **Stage 1 — Contains Duplicate**: does the array contain any duplicate at all?
2. **Stage 2 — Find the Duplicate Index**: where is the first duplicate, and can
   you find it in O(n) instead of O(n^2)?
3. **Stage 3 — Count Distinct Duplicated Values**: how many different values repeat?
4. **Stage 4 — Most Frequent Value**: which value shows up the most?
5. **Stage 5 — List All Duplicate Values**: print every repeated value, sorted.
6. **Stage 6 — Duplicate Within a Window of 3**: only nearby repeats count now.
7. **Stage 7 — Longest Subarray Without Duplicates**: the sliding-window finale.

Solve a stage and submit to unlock the next one.
