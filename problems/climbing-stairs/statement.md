# Climbing Stairs

You are climbing a staircase with `n` steps. Each time you may climb either **1** or **2**
steps. Count the number of distinct ways you can reach the top.

## Input

- Line 1: integer `n`.

## Output

A single integer: the number of distinct ways to reach step `n`.

## Example

Input:

```
3
```

Output:

```
3
```

The three ways are `1+1+1`, `1+2` and `2+1`.

## Constraints

- `1 <= n <= 45`

The answer fits comfortably in a 64-bit integer.
